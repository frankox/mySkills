# Onlitest Chatbot Handoff

Use this reference only when the teacher chooses Onlitest. Propose a populated version during collaborative planning and finalize it from the agreed assessment. Write the entire handoff in the assessment's language. The English template below defines the information to communicate, not a required output language.

Make it self-contained: the Onlitest chatbot must not need access to this conversation or private Notion links to reconstruct the assessment. Supply the relevant taught scope and full task text, not just source links. Replace placeholders with agreed content; resolve blocking gaps with the teacher and label any remaining optional unknowns. Do not include student identities or individual PDP records; describe only the functional arrangements relevant to configuring this assessment.

Use plain text or Markdown that can be copied into a chatbot. Do not claim this is an Onlitest import format or assume particular question types, attachments, grading automation, or platform settings are supported. If a proposed configuration depends on current platform capabilities, verify those through available authoritative documentation or ask the teacher before finalizing it.
