# Repository instructions

Write the README and all skills in English. This applies to skill names,
descriptions, instructions, supporting documentation, templates, and comments
in scripts created for skills. Preserve proper names and literal text when
their original language is required by the task.

Organize skills by domain in top-level folders, such as `projectManagement/`.
Keep each skill in its own self-contained subdirectory within its domain.

The English requirement applies to repository content. Artifacts produced by
a skill must follow the language required by the user or the destination
project; for example, Notion cards must use the language of their Notion project.
